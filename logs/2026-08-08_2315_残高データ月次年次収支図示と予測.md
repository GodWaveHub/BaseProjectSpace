# 残高データの月次・年次収支の図示と将来予測

- 実行日時: 2026-08-08 23:15 頃
- AI: GitHub Copilot CLI (VS Code)
- 実行時間: 約3分

## 指示内容

> 残高データより月ごと、年ごとの収入と支出を図示してください。
> 今後の伸び方を予測してください

対象データ: `money/data.txt`（2003/2〜2026/6 の残高スナップショット 248件）

## 実施内容

1. `SCRIPTS/analyze_balance.py` を作成
   - データ読み込み（タブ区切り、日付・残高）
   - 月末残高にリサンプリングし前月差分から純収入（増加）/純支出（減少）を算出
   - 年末残高から年間純増額を算出
   - 直近5年/10年の線形回帰、全期間の二次近似で将来予測（〜2036年）
2. 出力（`money/output/`）
   - `01_balance_trend.png` 残高推移
   - `02_monthly_income_expense.png` 月次増減
   - `03_yearly_income_expense.png` 年次増減
   - `04_forecast.png` 将来予測
   - `yearly_summary.csv` / `monthly_summary.csv`

## 主な結果

- 直近5年の増加ペース: 約223万円/年（約18.6万円/月）
- 直近10年の増加ペース: 約241万円/年（約20.1万円/月）
- 2030年末予測: 約4,600〜5,000万円
- 2036年末予測: 約5,900〜7,100万円

## 備考

- 途中でnumpy配列に`.values`を呼ぶ軽微なバグを修正して再実行
- データは残高スナップショットのため、収入・支出は「純増・純減」として推計
