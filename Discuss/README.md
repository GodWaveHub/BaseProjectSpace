# Discuss - subagents 合議の使い方

複数の custom subagents が議題に意見を述べ、互いの意見を踏まえて議論を深めます。最後にメインエージェントが統合します。
PowerShell は使わず、ファイルを用意して Copilot に話しかけるだけで合議が始まります。

---

## フォルダ構成

`
Discuss\
  ├── README.md                       # この使い方ガイド
  ├── discussion-spec.md              # 仕様書（設計の詳細）
  └── discussions\
       ├── topic-sample.md            # 議題テンプレート（汎用）
       ├── topic-sample-career.md     # 議題テンプレート（キャリア相談）
       ├── topic-sample-tech.md       # 議題テンプレート（技術選定）
       ├── agents-sample.md           # 参加エージェントテンプレート
       ├── topic-{id}.md              # 議題（入力）
       ├── agents-{id}.md             # 参加エージェント一覧（入力）
       ├── discussed-{id}.md          # 議論ログ・各ラウンドの発言（出力）
       └── conclusion-{id}.md         # 最終結論（出力）
`

{id} は連番（例: 001, 002）や任意の識別子（例: career, db-selection）でよい。
入力の topic-{id}.md と agents-{id}.md の {id} をそろえておくと、出力先も自動で決まる。

---

## 使い方（4ステップ）

### 1. 議題ファイルを作る

テンプレート discussions\topic-sample.md をコピーして {id} を付けたファイル名で保存し、内容を埋める。

議題ファイルの構成:

  ## テーマ: 検討したいテーマを1行で書く
  ## 背景・前提条件: 状況・制約を箇条書きで書く
  ## ゴール: このセッションで何を決めたいかを書く
  ## 検討観点（任意）: 重視したい論点があれば書く

### 2. 参加エージェントファイルを作る

テンプレート discussions\agents-sample.md をコピーして {id} を付けたファイル名で保存する。
行の順番が発言順になる。discuss.* 以外の custom subagent も列挙できる。

### 3. Copilot に依頼する

以下のように話しかけるだけで合議が始まる。

  Discuss\discussions\topic-001.md と agents-001.md を使って合議してください

ファイル名だけ変えれば何度でも再利用できる。

### 4. 出力ファイルを確認する

合議が終わると 2 つのファイルが生成される。

  discussed-{id}.md  ... 全ラウンドの発言ログ（ファシリテーションメモ付き）
  conclusion-{id}.md ... 合意点・対立点・未解決事項・推奨アクション（意思決定に使う）

---

## 参加エージェント一覧

  discuss.optimist    楽観的な友人。前向きな可能性と具体的な理由を示す
  discuss.cautious    慎重な友人。リスク・見落とし・代替案を指摘する
  discuss.humor       ユーモア担当。軽妙な切り口で本質を突く
  discuss.philosopher 哲学者。問題の本質と価値観の根底に問いを投げる

エージェントは agents-{id}.md に列挙したものだけが参加する。
目的に応じてメンバーを絞ったり、他の custom subagent を追加してもよい。

---

## 合議の流れ

**最大7ラウンド** で進む。議論が収束したら早期終了する。

  ラウンド1（初期意見）   各エージェントが独立して意見を1件述べる（他者の意見は見えない状態）
  収束判定              メインエージェントが「合意点・未解決論点」を評価する
  ラウンド2〜7          ファシリテーションメモ（合意要約・未解決点・次の焦点）を付けて再度全員が発言
  収束または7ラウンド到達 → 結論生成

**収束条件（いずれかで早期終了）:**
- 全員に共通する結論・推奨アクションが現れた
- 対立点が「条件付き合意」または「トレードオフの明示」で整理された
- 新しい論点が出なくなった（停滞）

7ラウンド到達後も収束しない場合は、残存する対立点を「未解決事項」として結論に記録する。

---

## 追加指示でラウンドを制御したい場合

会話で上限を変えることも可能。

  例: 3ラウンドで打ち切ってください
  例: 全員が結論を1行で言い切るラウンドを追加してください

## 旧方式（discuss.ps1）との違い

  実行方法         旧: PowerShell を手動実行       新: Copilot に話しかけるだけ
  設定方法         旧: 引数でパスやラウンド数を指定  新: ファイルを用意するだけ
  出力             旧: 発言ログ 1 ファイル          新: 議論ログ（全ラウンド）＋結論の 2 ファイル
  既定ラウンド数   旧: 複数ラウンド想定             新: 最大7ラウンド（収束で早期終了）
  ファシリテーション 旧: なし                       新: メインエージェントが毎ラウンド整理
  エージェント設定 旧: スクリプト内に固定           新: agents-{id}.md で管理
