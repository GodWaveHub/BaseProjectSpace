# 進捗率制御.yml 修正

- **実行日時**: 2026-05-24 12:37 UTC
- **AIモデル**: Claude Sonnet 4 (GitHub Copilot Agent)
- **所要時間**: 約5分

## 指示内容

機能２－２（画面）の進捗率を更新しましたが、親の「機能２－２」やさらに親の「機能２」の進捗率が更新されていません。進捗率制御.ymlを修正してください。

## 調査結果

### 根本原因
ワークフローログにて「進捗率[%]の変更なし。スキップします。」と出力されていた。

原因: `oldRate === newRate` の比較で、両方が `null` の場合（issueのbodyに「進捗率[%]: NUMBER」形式がない場合）、`null === null` が `true` となり早期終了していた。

### Issue状態
- Issue #9 (機能２－２（画面）): body = "テスト"（進捗率形式なし）
- Issue #7 (機能２－２): body = null
- Issue #4 (機能２): body = null
- サブissue階層は正しく設定済み（#9 → #7 → #4）

## 修正内容

`進捗率制御.yml` の進捗率変更検出ロジックを修正:

**変更前:**
```javascript
if (oldRate === newRate) {
  console.log('進捗率[%]の変更なし。スキップします。');
  return;
}
```

**変更後:**
```javascript
// 両方とも数値で同じ値の場合のみスキップ（null同士の場合はスキップしない）
if (oldRate !== null && newRate !== null && oldRate === newRate) {
  console.log('進捗率[%]の変更なし。スキップします。');
  return;
}
```

これにより、bodyに「進捗率[%]:」がない状態から追加する場合や、既存issueのbody編集時にも親の進捗率が再計算される。
