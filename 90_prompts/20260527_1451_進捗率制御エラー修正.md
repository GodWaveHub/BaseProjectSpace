## エラー原因

GitHub Actions の `GITHUB_TOKEN` に **GitHub Projects V2 の GraphQL API へのアクセス権限が不足**していた。

具体的には、`permissions` ブロックに Projects へのアクセス権限が定義されていなかった。

```
GraphqlResponseError: Request failed due to following response errors:
 - Resource not accessible by integration
```

## 修正内容

### 変更ファイル
`.github/workflows/進捗率制御.yml`

### 変更箇所

```yaml
# 修正前
permissions:
  issues: read
  contents: read

# 修正後
permissions:
  issues: read
  contents: read
  repository-projects: write  # リポジトリレベルの Projects アクセス（追加）
```

## ⚠️ 追加対応が必要な場合（Organization プロジェクト）

プロジェクトの Node ID が `PVT_kwHOA-wQNs4BYky6`（Organization レベル）であるため、
`GITHUB_TOKEN` だけでは権限が不足する可能性があります。

その場合は以下の手順で PAT を設定してください：

1. GitHub で Classic PAT を作成（スコープ: **`project`** にチェック）
2. `Settings > Secrets and variables > Actions > New repository secret`
3. 名前: `PAT_TOKEN`、値: 作成したPATを入力して保存

ワークフローはすでに `${{ secrets.PAT_TOKEN || secrets.GITHUB_TOKEN }}` で
PAT を優先使用する実装になっているため、登録するだけで有効になります。
