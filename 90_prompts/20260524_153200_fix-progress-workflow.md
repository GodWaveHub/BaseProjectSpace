# 進捗率制御ワークフロー修正

- **実行日時**: 2026-05-24 15:32 UTC
- **AIモデル**: Claude Sonnet 4
- **実行時間**: 約5分

## 指示内容

このactionの結果は間違っています。
機能２－２（画面）の"進捗率[%]"の値は、95であり、未設定ではありません。
workflowを見直して修正してください。

## 調査結果

ワークフロー実行ログを調査した結果、以下の2つの問題を発見:

1. **null → null のスキップ漏れ**: issueのbody編集時に、編集前後とも進捗率が設定されていない場合(null → null)でも親の再計算が実行され、進捗率未設定のサブissueが0%として計算されてしまう
2. **未設定サブissueの扱い**: 進捗率が未設定のサブissueを0%として平均に含めるため、正しく設定されたサブissueの進捗率が薄まる

## 修正内容

1. bodyの変更前後とも進捗率が未設定(null)の場合は早期リターンしてスキップ
2. 進捗率未設定のサブissueは平均計算から除外（0扱いではなく除外）
