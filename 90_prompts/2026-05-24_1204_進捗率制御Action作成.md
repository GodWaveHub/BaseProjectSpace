# 進捗率制御Action作成

## 実行情報
- **実行日時**: 2026-05-24 12:04 UTC
- **AIモデル**: Claude Sonnet 4 (GitHub Copilot)
- **種別**: Agent（コード生成）

## 指示内容
issuesの項目「進捗率[%]」について、動作するactionを作成する。
1. issue作成時に進捗率[%]を0で初期化する
2. issueの進捗率[%]を更新したとき、その親の進捗率[%]を見直す。親の進捗率[%]は親の配下の進捗率[%]の平均値とする。更新後、さらに親がある場合は、その親も更新する。親がなくなるまで繰り返す。
3. workflowsファイルのファイル名は「進捗率制御.yml」とする。

## 実行結果
- `.github/workflows/進捗率制御.yml` を作成
- issue bodyに「進捗率[%]: 数値」の形式でフィールドを管理
- GitHub Sub-Issues APIを使用して親子関係を取得
- 再帰的に親issueの進捗率を平均値で更新

## 技術的な補足
- トリガー: `issues` イベント（opened, edited）
- issue作成時: bodyに「進捗率[%]: 0」を追加
- issue編集時: bodyの変更を検知し、進捗率が変わった場合のみ親を更新
- 親の進捗率 = 子issueの進捗率の平均値（四捨五入）
- `actions/github-script@v7` を使用
- `github.rest.issues.listSubIssues` APIで子issue一覧を取得
- `parent_issue_url` フィールドで親issueを特定
