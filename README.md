# BaseProjectSpace

GitHub Copilot を活用したシステム開発プロジェクト管理ワークスペース

## このリポジトリの目的

GitHub Copilot を使い、プロジェクト全工程（見積 → 設計 → 実装 → テスト）の成果物を一元管理します。

## フォルダ構成

```
BaseProjectSpace/
├── 01_Estimate/        # 見積
├── 02_WBS/             # 作業分解構造
├── 03_Schedule/        # スケジュール管理
├── 04_Issues/          # 課題・リスク管理
├── 05_Progress/        # 進捗管理
├── 06_Meetings/        # 会議・議事録
├── 07_Design/          # 設計書
│   ├── 01_BasicDesign/     # 基本設計
│   ├── 02_DetailDesign/    # 詳細設計
│   └── 03_DatabaseDesign/  # データベース設計
│   └── 04_FileDesign/  # ファイル設計
│   └── 05_APIDesign/  # API設計
├── 08_Project/         # 実装（ソースコード）
├── 09_Test/            # テスト
│   ├── 01_UnitTest/        # 単体テスト
│   ├── 02_IntegrationTest/ # 組み合わせテスト
│   └── 03_SystemTest/      # システムテスト
├── SCRIPTS/            # スクリプト
└── logs/         # AIへの指示・実行ログ
```

## 各フォルダの説明

| フォルダ | 用途 | 格納ファイル例 |
|----------|------|----------------|
| 01_Estimate | 規模・工数・コストの見積 | 見積書、機能一覧、工数算出表 |
| 02_WBS | 作業の洗い出しと分解 | WBS表、タスク定義書 |
| 03_Schedule | スケジュール作成・進捗追跡 | ガントチャート、マイルストーン計画 |
| 04_Issues | 課題・リスクの識別と追跡 | 課題管理表、リスク管理表 |
| 05_Progress | 週次・月次の進捗報告 | 進捗報告書、実績管理表 |
| 06_Meetings | 会議の準備・実施・フォローアップ | 会議資料、議事録、アクションアイテム |
| 07_Design | 設計書の管理（基本・詳細・DB） | 設計書、ER図、API仕様書 |
| 08_Project | ソースコード・設定ファイル | プログラムコード、テストコード |
| 09_Test | テスト計画・実施・結果管理 | テスト仕様書、テストケース、結果報告 |
| SCRIPTS | スクリプト | PowerShellスクリプト等 |
| logs | AIへの指示内容と実行ログ | Markdownファイル（日時＋概要） |

> **注意**: テンプレート・フォーマットは各スキルの `assets/` フォルダに格納されています（`.github/skills/*/assets/`）。

## プロジェクト固有のルール

### プロジェクトのメンバーや単価、開発効率、見積定数
- プロジェクトで利用する変数は `PARAMETERS.md` の値を使ってください。
